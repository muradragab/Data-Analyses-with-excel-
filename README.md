# Data-Analyses-with-excel-


Project: Chocolate Sales Analyse in Excel

Data Cleaning: Removed Dupplicate , Removed formatting, standardized dates.

PivotTables: Grouped By

- Sales Per Sellers .
- Boxes shipped Per Sellers .
- Sales Per Countries .
- boxes Shipped Per Countries.
- Sales Per Month .
- Count of Boxes Shipped Per month .
- Sales By Products .

Visualization: Created charts (bar/line/pie) to show trends.

Dashboard: Built interactive report with slicers.
